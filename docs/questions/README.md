# PMP試験問題集

このディレクトリには、PMP（Project Management Professional）試験対策用の問題集が含まれています。

## 📚 含まれるファイル

### 日本語版
- **最新問題50問 V25R01**: PMP試験形式に準拠した最新の練習問題
- **解答・解説**: 各問題の詳細な解答と解説
- **解答用紙**: 印刷して使用できる解答記入用紙

### English Version
- **Latest Questions 50 Items V25R01**: Latest practice questions aligned with PMP exam format
- **Answers & Explanations**: Detailed answers and explanations for each question
- **Answer Sheet**: Printable answer sheet for practice

## 📝 使用方法

1. **学習モード**: 問題と解答・解説を併用して学習
2. **テストモード**: 解答用紙を使用して実際の試験形式で練習
3. **復習モード**: 間違えた問題を中心に解説を確認

## ⚠️ 注意事項

- これらの問題は学習目的でのみ使用してください
- 実際のPMP試験問題とは異なる場合があります
- 定期的に最新版への更新を確認してください

## 🎯 学習のポイント

- PMBOKガイドの各知識エリアをバランスよく学習
- 実際の試験時間を意識した時間配分の練習
- 解説を通じてPMの実践的な考え方を習得
