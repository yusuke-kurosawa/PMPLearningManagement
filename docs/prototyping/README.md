## フィードバック収集機構

### PrototypeFeedbackForm
包括的なフィードバック収集システムを実装:

**5段階フロー**:
1. 基本情報（氏名、経験レベル、テスト日）
2. バンドルサイズ最適化評価
3. PWAオフライン機能評価
4. AIコーチング評価
5. 総合評価（NPS、優先改善機能）

**評価指標**:
- タスク完了チェックリスト
- 5段階星評価（★★★★★）
- NPS（Net Promoter Score）: 0-10スケール
- 自由記述フィードバック

**ファイル**: `src/components/prototyping/PrototypeFeedbackForm.tsx` (709行)

## ユーザーテスト計画

### 対象参加者
- **総数**: 15名
  - 初学者: 5名（PMP学習開始前〜3ヶ月）
  - 学習中: 5名（3ヶ月〜試験前）
  - 再受験者: 5名

### テストフロー（所要時間: 45分）
1. **事前説明**: 5分
2. **プロトタイプ体験**: 30分
   - プログレッシブローディング: 10分
   - オフラインモード: 10分
   - AIコーチング: 10分
3. **フィードバック収集**: 10分

### 評価指標

#### 定量指標
| 指標 | 目標値 | 計測方法 |
|------|--------|----------|
| タスク完了率 | > 90% | チェックリスト |
| 平均完了時間 | < 30分 | タイマー |
| エラー発生率 | < 5% | 操作ログ |
| NPS | > 50 | アンケート |
| CSAT (満足度) | > 4.0/5 | 星評価 |

#### 定性指標
- ユーザーの口頭フィードバック
- 操作時の表情・反応観察
- 自由記述コメント分析
- 改善提案の収集

## 使用方法

### ステップ1: ルーティング追加
`src/App.jsx` にルートを追加:

```tsx
import {
  ProgressiveLoadingPrototype,
  OfflineModePrototype,
  AICoachingPrototype,
  PrototypeFeedbackForm
} from './components/prototyping'

<Routes>
  <Route path="/prototypes/progressive-loading" element={<ProgressiveLoadingPrototype />} />
  <Route path="/prototypes/offline-mode" element={<OfflineModePrototype />} />
  <Route path="/prototypes/ai-coaching" element={<AICoachingPrototype />} />
  <Route path="/prototypes/feedback" element={<PrototypeFeedbackForm />} />
</Routes>
```

### ステップ2: アクセス
開発サーバー起動後、以下のURLにアクセス:
- `http://localhost:5173/#/prototypes/progressive-loading`
- `http://localhost:5173/#/prototypes/offline-mode`
- `http://localhost:5173/#/prototypes/ai-coaching`
- `http://localhost:5173/#/prototypes/feedback`

### ステップ3: ユーザーテスト実施
1. 参加者にURLを提供
2. タスクを順次実行してもらう
3. フィードバックフォームで評価を収集
