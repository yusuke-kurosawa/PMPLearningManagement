## 🎯 1. プロジェクト・スコープの説明

### 1.1 プロジェクト目的

PMPLearningManagementプロジェクトは、PMP（Project Management Professional）資格取得を目指す学習者のための包括的な学習管理システムを開発し、効率的な学習体験を提供することを目的とします。

### 1.2 プロジェクト目標（SMART目標）

| 目標 | 測定基準 | 目標値 | 達成期限 |
|------|----------|--------|----------|
| **S**pecific: バンドルサイズ最適化 | バンドルサイズ（MB） | 1.3MB→500KB（62%削減） | Phase 1完了時 |
| **M**easurable: PWA機能実装 | オフライン機能利用率 | 50%以上の学習セッション | Phase 1完了時 |
| **A**chievable: API統合完了 | APIエンドポイント実装率 | 50+エンドポイント100% | Phase 2-3完了時 |
| **R**elevant: 学習効率向上 | 学習時間短縮率 | 30%以上向上 | Phase 4完了時 |
| **T**ime-bound: プロジェクト完了 | 全フェーズ完了 | 100%（6ヶ月） | 2026-03-28 |

### 1.3 プロジェクト正当性

**ビジネスニーズ**:
- PMP資格取得の需要増加（年間10%成長）
- 既存学習ツールの不足（包括的視覚化・分析機能の欠如）
- 効率的な学習方法の必要性

**期待されるビジネス価値**:
- 学習時間30%短縮によるユーザー満足度向上
- 試験合格率向上によるブランド価値向上
- 年間推定ROI: 500-800万円

## 🚫 5. スコープ外の項目

以下の項目は、本プロジェクトのスコープに**含まれません**：

### 5.1 機能的スコープ外

| 項目 | 理由 | 将来検討 |
|------|------|----------|
| **ネイティブモバイルアプリ** | リソース不足、PWAで対応 | Phase 5以降 |
| **決済システム統合** | ビジネスモデル未確定 | Phase 5以降 |
| **ゲーミフィケーション** | 優先度低（Could Have） | Phase 5以降 |
| **ソーシャルメディア統合** | セキュリティリスク | 検討中 |
| **カスタムテーマ作成機能** | ユーザーニーズ不明確 | ユーザーフィードバック後 |
| **音声読み上げ機能** | アクセシビリティ優先度低 | Phase 5以降 |
| **動画コンテンツ** | 制作コスト高 | 外部連携検討 |
| **バックエンド管理画面** | 1名体制での実装困難 | Phase 6以降 |

### 5.2 技術的スコープ外

| 項目 | 理由 |
|------|------|
| **マイクロサービスアーキテクチャ** | 現段階では過剰設計 |
| **Kubernetes デプロイ** | GitHub Pages使用 |
| **GraphQL API** | tRPCで十分 |
| **サーバーサイドレンダリング** | 静的サイト要件 |
| **カスタム認証システム** | Supabase使用 |

### 5.3 プロジェクト管理スコープ外

| 項目 | 理由 |
|------|------|
| **複数拠点チーム管理** | 1名体制 |
| **調達管理** | 外部発注なし |
| **複雑なステークホルダー管理** | 限定的ステークホルダー |

| 制約 | 詳細 | 対応策 |
|------|------|--------|
| **GitHub Pages** | 静的サイトホスティングのみ | HashRouter使用、API分離 |
| **LocalStorage制限** | 5-10MB制限 | IndexedDB移行（Phase 2-3） |
| **ブラウザ互換性** | モダンブラウザのみ | IE11非対応明示 |
| **バンドルサイズ** | 初期ロード3秒制約 | 遅延ロード、Tree-shaking |

### 6.3 外部依存性制約

| 制約 | 詳細 | リスク |
|------|------|--------|
| **Supabase API** | 無料プラン制限 | API呼び出し制限 |
| **LLM API** | OpenAI/Anthropic API | コスト、レート制限 |
| **GitHub Actions** | 実行時間制限 | CI/CDパイプライン最適化必要 |

### 6.4 規制・コンプライアンス制約

| 制約 | 詳細 | 対応 |
|------|------|------|
| **GDPR** | EU個人情報保護規則 | Cookie同意、データ削除機能 |
| **WCAG 2.1** | アクセシビリティ基準 | AA準拠実装 |
| **PMI著作権** | PMBOK内容の使用制限 | 引用ルール遵守、オリジナル解説 |
