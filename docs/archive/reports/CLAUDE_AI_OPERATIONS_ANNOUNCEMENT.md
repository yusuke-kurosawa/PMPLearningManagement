# 🚀 Claude AI統合機能 - 本番運用開始のお知らせ

**発効日**: 2025年8月10日  
**対象**: PMPLearningManagement プロジェクト全体  
**ステータス**: 本番運用開始

## 📢 重要なお知らせ

PMPLearningManagementプロジェクトにおいて、Claude AI統合機能の本番運用を**本日より正式に開始**いたします。

## 🎯 利用可能な機能

### 1. ✅ Issue Handler（動作確認済み・本番運用中）

**機能**: 新しいIssue作成時の自動分析・ラベル付与

**自動実行項目**:

- Issue内容の自動分析
- 適切なラベルの自動付与（`needs-triage`, `priority:low/medium/high/critical`）
- `claude-analyzed`ラベルの自動追加
- 分析結果コメントの自動投稿

**トリガー**: 新しいIssueの作成時

### 2. ✅ PR Review（動作確認済み・本番運用中）

**機能**: プルリクエスト作成時の自動コードレビュー

**自動実行項目**:

- コード変更の自動分析
- 品質改善提案の生成
- 潜在的な問題点の指摘
- 建設的なフィードバックの提供

**トリガー**: PRの作成・更新時

### 3. ⚠️ @Claude メンション機能（修正作業中）

**機能**: @claudeメンションによる対話型サポート

**現状**: API応答エラーのため一時的に制限中  
**修正予定**: Phase 2で完全復旧予定

## 📋 使用方法・ベストプラクティス

### Issue作成時の推奨方法

1. **明確なタイトル**: 問題や要望を簡潔に表現

   ```
   良い例: "フラッシュカード機能でページが白くなる不具合"
   悪い例: "バグ"
   ```

2. **詳細な説明**:
   - 現象の説明
   - 再現手順
   - 期待する動作
   - 環境情報

3. **自動ラベルの活用**:
   - Claude AIが自動付与するラベルを確認
   - 必要に応じて追加のラベルを手動付与

### PR作成時の活用方法

1. **明確なPR説明**:
   - 変更内容の概要
   - 変更理由
   - テスト内容

2. **Claude AIレビューの活用**:
   - 自動生成されるレビューコメントを確認
   - 提案された改善点を検討・実装
   - 人間のレビュアーとの相補的活用

3. **品質向上への貢献**:
   - 指摘された問題点の修正
   - 提案されたベストプラクティスの採用

## ⚠️ 注意事項・制限

### 現在の制限事項

1. **@claudeメンション機能**: API応答エラーのため制限中
2. **日本語対応**: 一部英語での応答の場合があります
3. **複雑な分析**: 非常に複雑なケースでは人間の判断が必要

### セキュリティ・プライバシー

- すべてのAI処理は暗号化された通信で実行
- 機密情報は自動的に除外される仕組みを実装
- ログは適切な期間で自動削除

## 🛠️ トラブルシューティング

### よくある問題

1. **AIが応答しない**
   - ワークフローの実行状況を確認
   - GitHubActionsのログを確認
   - 必要に応じて手動でワークフローを再実行

2. **不適切なラベル付与**
   - 手動でラベルを修正
   - フィードバックをIssueコメントで報告

3. **レビューコメントが表示されない**
   - PR作成から5分程度待つ
   - GitHubActionsの実行状況を確認
