# PMPLearningManagement システム要求事項定義書

**バージョン**: 2.0.0
**最終更新**: 2025-09-28
**ステータス**: アクティブ（継続更新）
**プロジェクトURL**: https://yusuke-kurosawa.github.io/PMPLearningManagement/

---

## エグゼクティブサマリー

PMPLearningManagementは、PMP（Project Management Professional）資格取得を支援する包括的Web学習プラットフォームです。PMBOK第6版・第7版に完全準拠し、49プロセス、12プリンシプル、8パフォーマンスドメイン、ITTOフレームワークを多様な視覚化手法と学習ツールで提供します。

### システム概要
- **アーキテクチャ**: React 18.2 + Vite + PWA対応
- **デプロイ環境**: GitHub Pages（静的サイトホスティング）
- **現在の成熟度**: フロントエンド完成（60+コンポーネント）、バックエンド統合準備中
- **ユーザーベース**: PMP受験者、プロジェクトマネジメント学習者

## 1. 機能要求（Functional Requirements）

### 1.1 PMP学習支援機能【必須】

#### FR-1.1.1: PMBOKマトリックスビュー
- **説明**: 10知識エリア × 5プロセス群の対話型マトリックス表示
- **優先度**: 必須（P0）
- **実装状況**: ✅ 完成
- **受容基準**:
  - 49プロセスすべてがマトリックス上に配置されていること
  - 各セルクリックで詳細情報が表示されること
  - フィルタリング機能（知識エリア別、プロセス群別）が動作すること
  - レスポンシブデザインで表示が崩れないこと

  - ノードクリックで詳細情報がポップアップ表示されること

## 2. 非機能要求（Non-Functional Requirements）

### 2.1 パフォーマンス要求【必須】

#### NFR-2.1.1: 初期ロード時間
- **要求**: 初回ロード3秒以内（3G回線環境）
- **優先度**: 必須（P0）
- **現在の状態**: ✅ 達成（2.8秒）
- **測定方法**: Lighthouse Performance、WebPageTest
- **受容基準**:
  - FCP (First Contentful Paint) < 1.8秒
  - LCP (Largest Contentful Paint) < 2.5秒
  - TTI (Time to Interactive) < 3.8秒

#### NFR-2.1.2: バンドルサイズ
- **要求**: 初期バンドル500KB以下（gzip圧縮後）
- **優先度**: 必須（P0）
- **現在の状態**: ⚠️ 要改善（1.3MB）
- **測定方法**: Webpack Bundle Analyzer、bundlesize
- **受容基準**:
  - 初期バンドル < 500KB
  - 非同期チャンク < 200KB
  - 総バンドル < 2MB

#### NFR-2.1.3: レスポンシブネス
- **要求**: ユーザー操作後100ms以内の視覚的フィードバック
- **優先度**: 必須（P0）
- **現在の状態**: ✅ 達成
- **測定方法**: Chrome DevTools Performance
- **受容基準**:
  - FID (First Input Delay) < 100ms
  - インタラクション遅延 < 50ms
  - アニメーション60fps維持

#### NFR-2.1.4: メモリ使用量
- **要求**: メモリリークなし、最大メモリ使用量500MB以下
- **優先度**: 重要（P1）
- **現在の状態**: ✅ 達成（380MB）
- **測定方法**: Chrome DevTools Memory Profiler
- **受容基準**:
  - 長時間利用後もメモリ使用量増加なし
  - ガベージコレクション正常動作

## 3. 制約条件（Constraints）

### 3.1 技術的制約

#### TC-3.1.1: ホスティング環境
- **制約**: GitHub Pages静的サイトホスティング（サーバーサイド処理不可）
- **影響**: バックエンドAPI統合にはCloudflare Workers/Vercelなど外部サービス必要
- **対応**: Supabase BaaS活用、tRPC + Cloudflare Workers統合計画

#### TC-3.1.2: ブラウザ制約
- **制約**: ブラウザAPIの互換性制限
- **影響**: 一部最新APIが古いブラウザで動作しない
- **対応**: Polyfill導入、フィーチャー検出実装

#### TC-3.1.3: パフォーマンス制約
- **制約**: D3.js視覚化の大規模データ処理でのパフォーマンス低下
- **影響**: 1000ノード以上のグラフでレンダリング遅延
- **対応**: データ仮想化、Web Worker活用、レイアウト最適化

#### TC-3.1.4: ストレージ制約
- **制約**: LocalStorage 5-10MB制限
- **影響**: 大量の学習データ保存に限界
- **対応**: IndexedDB移行計画、サーバーサイドストレージ統合

### 3.2 ビジネス制約

#### BC-3.2.1: ライセンス
- **制約**: PMBOK®はPMI登録商標、コンテンツ利用には制限あり
- **影響**: PMBOKコンテンツの二次利用制限
- **対応**: オリジナルコンテンツ作成、PMI公式コンテンツへのリンク

#### BC-3.2.2: 予算
- **制約**: 無料ホスティング利用、有料サービス最小化
- **影響**: インフラ選択の制限
- **対応**: オープンソース活用、無料枠内での運用

#### BC-3.2.3: リソース
- **制約**: 1名体制での開発
- **影響**: 開発スピード・機能範囲の制限
- **対応**: 優先順位明確化、自動化推進、IDD実践

### 3.3 規制・コンプライアンス

#### RC-3.3.1: データ保護規制
- **制約**: GDPR、個人情報保護法準拠必要
- **影響**: データ管理プロセスの複雑化
- **対応**: プライバシーポリシー整備、同意管理実装

#### RC-3.3.2: アクセシビリティ規制
