# OPM学習コンポーネント デモガイド

## 概要
PMPLearningManagementプロジェクトに、OPM（組織のプロジェクトマネジメント）と組織構造タイプの学習コンポーネントを新規作成しました。

## 作成したコンポーネント

### 1. OPMLearningHub (`/src/components/learning/OPMLearningHub.tsx`)

**機能:**
- OPMフレームワークの3階層（ポートフォリオ、プログラム、プロジェクト）を学習
- インタラクティブなタブ形式UI（階層構造、価値の流れ、導入効果、ロードマップ）
- 各階層の詳細情報展開機能
- ダークモード対応
- アニメーション付きUI

**アクセス方法:**
- URL: `/opm-learning`
- ナビゲーション: "OPM学習ハブ"

**主な機能:**
- **階層構造タブ**: 3つの階層をカード形式で表示、クリックで詳細展開
- **価値の流れタブ**: 戦略的整合性（Top-Down）と価値の流れ（Bottom-Up）を視覚化
- **導入効果タブ**: 組織的・財務的・運用的・戦略的効果を分類表示
- **ロードマップタブ**: 3段階の実装フェーズを段階的に表示

### 2. OPMHierarchyDiagram (`/src/components/visualizations/OPMHierarchyDiagram.tsx`)

**機能:**
- OPMの3階層をピラミッド型ダイアグラムで視覚化
- D3.jsベースの高品質な図表
- アニメーション機能（戦略の流れ、価値の流れ）
- レスポンシブデザイン
- SVGエクスポート機能

**アクセス方法:**
- URL: `/opm-hierarchy`
- ナビゲーション: "OPM階層図"

**主な機能:**
- **静的表示**: 基本的な階層構造を表示
- **戦略アニメーション**: Top-Downの戦略的整合性の流れをパーティクルで表現
- **価値アニメーション**: Bottom-Upの価値の流れをパーティクルで表現
- **ホバー詳細**: ノードをホバーでツールチップ表示
- **クリック詳細**: ノードクリックで詳細パネル展開

### 3. OrganizationStructureComparison (`/src/components/learning/OrganizationStructureComparison.tsx`)

**機能:**
- 機能型、マトリックス型、プロジェクト型組織の詳細比較
- インタラクティブな比較表、権限レベルチャート、レーダーチャート
- 組織構造推奨エンジン

**アクセス方法:**
- URL: `/organization-structure`
- ナビゲーション: "組織構造比較"

**主な機能:**
- **比較表タブ**: 5つの観点で3つの組織タイプを比較
- **権限レベルタブ**: PMの権限レベルを棒グラフで比較
- **レーダーチャートタブ**: 6つの特性をレーダーチャートで可視化
- **推奨エンジンタブ**: プロジェクト特性に基づいて最適な組織タイプを推奨

## 技術仕様

### 使用技術
- **React 18**: 関数コンポーネント + Hooks
- **TypeScript**: 型安全性の確保
- **Framer Motion**: アニメーション
- **D3.js**: データ視覚化（OPMHierarchyDiagram）
- **Tailwind CSS**: スタイリング
- **Radix UI**: アクセシブルなUIコンポーネント
- **Lucide React**: アイコン

### データソース
- `/src/data/pmbok/opmData.js`: OPMフレームワークと組織構造の完全なデータセット
- `/src/data/schemas/pmbok/opmTypes.ts`: TypeScript型定義

### 設計パターン
- **レスポンシブデザイン**: モバイルファーストアプローチ
- **ダークモード対応**: 全コンポーネントでテーマ切り替え対応
- **アクセシビリティ**: ARIA対応、キーボードナビゲーション
- **コードスプリッティング**: React.lazyによる遅延読み込み

## 使用方法

1. **基本的な学習フロー:**
   - OPM学習ハブで概念を理解
   - OPM階層図で視覚的に確認
   - 組織構造比較で詳細を学習

2. **推奨される学習順序:**
   1. OPM学習ハブの「階層構造」タブで基本概念
   2. 「価値の流れ」タブで関係性理解
   3. OPM階層図でアニメーション確認
   4. 組織構造比較で実践的な選択方法を学習

3. **実践的な活用:**
   - 推奨エンジンで実際のプロジェクトに適用
   - レーダーチャートで組織特性を比較
   - 権限レベルでPMの役割を理解
