## 🎯 学習者タイプ別ガイド

### 初学者（PM経験なし）

1. [クイックスタート](./quick-start.md)から開始
2. [PMBOKの基礎](./tutorials/pmbok-basics.md)を学習
3. [用語集](./features/glossary.md)で基本用語をマスター

### 経験者（PM経験あり）

1. [診断テスト](./features/diagnostic-test.md)で現在レベル確認
2. [ギャップ分析](./features/gap-analysis.md)で弱点特定
3. [カスタム学習プラン](./features/custom-plan.md)を作成

### 再受験者

1. [前回の分析](./features/exam-analysis.md)で失敗要因を特定
2. [集中学習モード](./features/intensive-mode.md)で弱点克服
3. [メンターサポート](./features/mentorship.md)を活用

## 📊 学習成果の最大化

### 推奨学習サイクル

```
月曜日: 新規コンテンツ学習（2時間）
火曜日: 演習問題（1時間）
水曜日: グループディスカッション（1時間）
木曜日: 復習とノート整理（1時間）
金曜日: ミニ模擬試験（1時間）
土曜日: 弱点領域の集中学習（2時間）
日曜日: 週次振り返りと計画（30分）
```

### 成功のための5つのポイント

1. **継続性** - 毎日最低30分の学習
2. **実践** - 知識を実務に適用
3. **コミュニティ** - 他の学習者と交流
4. **フィードバック** - AIコーチの提案を活用
5. **振り返り** - 定期的な進捗確認
