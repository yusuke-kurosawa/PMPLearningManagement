## 🎯 3つのステップで学習開始

### ステップ 1: アカウント作成（1分）

1. [PMP Learning Management](https://yusuke-kurosawa.github.io/PMPLearningManagement/)にアクセス
2. 「無料で始める」ボタンをクリック
3. メールアドレスとパスワードを入力
4. 確認メールのリンクをクリック

✅ **完了！** アカウントが有効化されました

### ステップ 2: 学習目標の設定（2分）

ログイン後、初期設定ウィザードが表示されます：

1. **PMP受験予定日を選択**
   - 3ヶ月後
   - 6ヶ月後
   - 1年後
   - まだ決めていない

2. **現在の経験レベルを選択**
   - PM経験なし（初学者）
   - 1-3年のPM経験
   - 3年以上のPM経験
   - PMP更新目的

3. **1日の学習時間を設定**
   - 30分
   - 1時間
   - 2時間以上

🎉 **パーソナライズ完了！** あなた専用の学習プランが生成されました

### ステップ 3: 最初のレッスンを開始（2分）

ダッシュボードから推奨される最初のレッスンを選択：

**初学者の方**
→ 「PMBOKの全体像を理解する」から開始

**経験者の方**
→ 「診断テスト」で現在のレベルを確認

## 📚 最初の学習セッション

### 🎓 レッスン1: PMBOKの全体像（15分）

#### 学習目標
- PMBOKの5つのプロセス群を理解する
- 10の知識エリアの概要を把握する
- 49のプロセスの関係性を視覚的に理解する

#### 学習の流れ

1. **動画講義を視聴**（5分）
   - PMBOKの歴史と重要性
   - なぜPMBOKが世界標準なのか

2. **インタラクティブマトリックスを探索**（5分）
   - [PMBOKマトリックスビュー](#/matrix)にアクセス
   - 各プロセスをクリックして詳細を確認
   - プロセス間の関係を視覚的に理解

3. **理解度チェッククイズ**（5分）
   - 5問の選択式問題
   - 即座にフィードバック提供
   - 間違えた問題は復習リストに追加

#### 🏆 最初のバッジを獲得！
「PMBOKエクスプローラー」バッジが付与されます

## 💡 学習効果を最大化するコツ

### 📅 毎日の習慣化

**朝の通勤時間を活用**
- モバイルアプリで5分間のマイクロラーニング
- フラッシュカードで用語を暗記

**昼休みに復習**
- AIコーチが提案する復習問題を解く
- 前日の学習内容を確認

**就寝前の振り返り**
- 今日学んだことを3つ書き出す
- 明日の学習目標を設定

### 🎯 効果的な学習方法

1. **視覚化ツールを活用**
   - 複雑な概念は図解で理解
   - ネットワーク図でプロセスの流れを把握

2. **アクティブラーニング**
   - 読むだけでなく、クイズに挑戦
   - 学習グループでディスカッション

3. **定期的な振り返り**
   - 週次で進捗を確認
   - 月次で模擬試験に挑戦

### 🤝 コミュニティの活用

**スタディグループに参加**
- 同じ目標を持つ仲間と学習
- 疑問点をすぐに解決

**メンターを見つける**
- PMP合格者からアドバイス
- 実践的なコツを学ぶ
