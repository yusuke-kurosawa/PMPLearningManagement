## 🌟 主要機能

- **インタラクティブPMBOKマトリックス**: 49プロセスの視覚的表現
- **動的ネットワーク図**: D3.js駆動のプロセス関係図
- **包括的用語集**: 45以上の重要なPMP用語
- **模擬試験**: 180問のシミュレーション試験
- **進捗追跡**: 詳細な学習分析
- **協調学習**: 学習グループと共有ノート
