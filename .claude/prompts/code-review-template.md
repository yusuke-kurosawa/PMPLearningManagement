### セキュリティ特化レビューテンプレート

```
PMPLearningManagementプロジェクトのセキュリティレビューを実行してください。

## 🔒 セキュリティ重点項目
1. **認証・認可**: JWT実装、権限チェック、セッション管理
2. **XSS防止**: 入力サニタイゼーション、出力エスケープ
3. **機密情報**: ハードコーディング回避、環境変数使用
4. **依存関係**: 脆弱性のあるパッケージ検出
5. **CSRF対策**: トークン検証、SameSite Cookie

## 📊 セキュリティ評価基準
- 🔴 Critical: 即座の修正が必要（9-10点の脆弱性）
- 🟡 High: 優先的な修正が必要（7-8点の脆弱性）
- 🟢 Medium: 時間のあるときに修正（5-6点の脆弱性）
- ⚪ Low: 軽微な改善提案（1-4点の脆弱性）

期待する出力: セキュリティスコア、脆弱性一覧、修正提案
```

### パフォーマンス特化レビューテンプレート

```
PMPLearningManagementプロジェクトのパフォーマンスレビューを実行してください。

## ⚡ パフォーマンス重点項目
1. **React最適化**: メモ化、再レンダリング防止
2. **バンドルサイズ**: 不要インポート、Tree shaking
3. **ロード時間**: 遅延ロード、コード分割
4. **メモリ使用量**: メモリリーク防止
5. **ネットワーク**: API呼び出し最適化

## 📊 パフォーマンス指標
- Bundle Size: 目標 < 500KB gzipped
- First Contentful Paint: < 1.5s
- Largest Contentful Paint: < 2.5s
- Cumulative Layout Shift: < 0.1

期待する出力: パフォーマンススコア、最適化提案、Core Web Vitals予測
```

## 📚 レビュー時の参考情報

### プロジェクト固有の考慮事項
- **学習アプリケーション**: ユーザー体験重視
- **PWA対応**: オフライン機能、パフォーマンス
- **多言語対応**: 国際化対応
- **アクセシビリティ**: PMP学習者の多様性に配慮

### よくある指摘事項
1. **型定義不足**: `any`型の多用
2. **useEffect依存配列**: 不適切な依存関係
3. **メモ化不足**: 不要な再レンダリング
4. **エラーハンドリング**: 例外処理の不備
5. **テスト不足**: カバレッジ不足
