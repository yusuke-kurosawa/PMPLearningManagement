# Coordination エージェント

エージェント間の調整・統合に特化したエージェント群です。

## エージェント選択ガイド

| エージェント | 適用場面 | 主な職責 |
|------------|----------|----------|
| **agent-organizer** | エージェント編成・最適化 | ワークフロー設計、チーム編成 |
| **context-manager** | コンテキスト管理・状態同期 | 共有状態管理、データ同期 |

## 推奨使用パターン

- **複雑なマルチエージェント作業**: agent-organizer + context-manager
- **大規模プロジェクト管理**: agent-organizer
- **状態管理最適化**: context-manager
