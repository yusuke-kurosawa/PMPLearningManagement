# 📊 Management エージェントカテゴリ

> **重要**: このディレクトリはプロジェクト管理とプロダクト戦略に特化したClaude Codeエージェントを管理します。

## 📋 概要

Managementカテゴリは、プロジェクト管理、プロダクト戦略、アジャイル開発、ビジネス分析を担当する管理専門エージェント群です。効果的なプロジェクト推進と価値提供を支援します。

## 🤖 配置エージェント

### project-manager.md
**プロジェクト管理専門エージェント**

#### 専門領域
- プロジェクト計画策定
- 進捗管理とレポーティング
- リスク管理と課題解決
- リソース配分最適化
- ステークホルダー管理

#### 主要成果物
- WBS（作業分解構造）
- ガントチャート
- リスク管理台帳
- 進捗レポート
- リソース計画書

#### 主要タスク
```bash
# プロジェクト計画
@agent-project-manager プロジェクト計画を策定してください

# 進捗管理
@agent-project-manager 現在の進捗状況をレポートしてください

# リスク分析
@agent-project-manager プロジェクトリスクを分析して対策を提案してください
```

## 🎯 使用シナリオ

### プロジェクト立ち上げフロー
```bash
# 1. ビジネス要件分析
@agent-business-analyst ビジネス要件を分析してください

# 2. プロダクト戦略策定
@agent-product-manager プロダクトビジョンとロードマップを作成してください

# 3. プロジェクト計画
@agent-project-manager 詳細なプロジェクト計画を策定してください

# 4. アジャイル導入
@agent-scrum-master スクラムフレームワークを導入してください
```

### スプリント実行フロー
```bash
# 1. スプリント計画
@agent-scrum-master スプリント計画ミーティングを実施してください

# 2. デイリー進捗管理
@agent-project-manager 日次進捗を確認してください

# 3. 障害対応
@agent-scrum-master 発生した障害を除去してください

# 4. スプリントレビュー
@agent-product-manager スプリント成果をレビューしてください
```

## 🎮 ベストプラクティス

### ✅ 推奨事項

1. **透明性の確保**
   - 進捗の可視化
   - 定期的なコミュニケーション
   - ドキュメントの整備

2. **継続的改善**
   - レトロスペクティブの実施
   - メトリクスの追跡
   - フィードバックループ

3. **ステークホルダー管理**
   - 期待値の調整
   - 定期的な報告
   - 早期の問題共有

### ❌ 避けるべきこと

1. **過度な管理**
   - マイクロマネジメント
   - 過剰なドキュメント
   - 硬直的なプロセス

2. **コミュニケーション不足**
   - サイロ化
   - 情報の抱え込み
   - フィードバックの欠如
