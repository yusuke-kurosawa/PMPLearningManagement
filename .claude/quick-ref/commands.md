## Essential Commands

```bash
# Development
npm run dev          # Start development server
npm run build        # Production build
npm run test         # Run tests

# IDD Workflow
npm run idd:check    # Check IDD compliance
npm run idd:status   # Show IDD status
npm run idd:hooks:install  # Install Git hooks

# Context Management
npm run context:update     # Update context
npm run context:cleanup    # Clean context cache
```

## Quick Actions

- **Start Development**: `npm run dev`
- **Run All Tests**: `npm run test && npm run test:e2e`
- **Deploy**: `npm run build && npm run deploy`
- **IDD Setup**: `npm run idd:setup && npm run idd:hooks:install`
