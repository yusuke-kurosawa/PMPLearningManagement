## Critical Files

```bash
# Configuration
CLAUDE.md                    # Project instructions for Claude
.eslintrc.json              # ESLint configuration
vite.config.js              # Vite build configuration
tailwind.config.js          # Tailwind CSS configuration

# Entry Points
src/main.jsx                # React application entry
src/App.jsx                 # Main app component
index.html                  # HTML template

# Key Directories
src/components/             # React components
src/contexts/               # React contexts
src/services/               # Business logic services
src/data/                   # Static data definitions
```

## Quick Navigation

- **Components**: `src/components/[category]/ComponentName.jsx`
- **Services**: `src/services/serviceName.js`
- **Tests**: `src/components/__tests__/` or adjacent `.test.js`
- **Documentation**: `docs/[category]/`
- **Claude Context**: `.claude/context/`
