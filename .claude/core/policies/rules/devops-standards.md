# DevOps Standards & Rules

このファイルはPMPLearningManagementプロジェクトのDevOps標準とルールを定義します。

## 🎯 CI/CDパイプライン標準

### ワークフロー命名規則

```yaml
# 規則: [カテゴリ] [目的] [詳細説明]
# 例: 🚀 統合CI/CDパイプライン
name: 🚀 統合CI/CDパイプライン
```

### 必須品質ゲート

1. **ESLintチェック**: エラー0個、警告は許可
2. **TypeScriptチェック**: 型エラー0個
3. **テストカバレッジ**: 80%以上
4. **ビルド成功**: 100%成功率
5. **セキュリティ監査**: 高/重要な脆弱性0個

### ワークフロー実行時間制限

- Pre-flight: 5分以内
- Quality Gates: 10分以内
- Testing: 15分以内
- Build & Deploy: 10分以内
- 総実行時間: 40分以内

## 🔧 技術標準

### Node.js環境

- **標準バージョン**: Node.js 18
- **パッケージマネージャー**: npm
- **キャッシュ戦略**: GitHub Actionsキャッシュ活用

### 依存関係管理

```bash
# インストール標準
npm ci --prefer-offline --no-audit

# セキュリティ監査
npm audit --audit-level=high
```

### テスト戦略

- **単体テスト**: Vitest
- **統合テスト**: API/コンポーネント統合
- **E2Eテスト**: Playwright
- **アクセシビリティテスト**: axe-core

## 📊 監視・メトリクス

### 必須監視項目

1. **ビルド成功率**: 95%以上
2. **テスト成功率**: 100%
3. **デプロイ成功率**: 100%
4. **実行時間**: 閾値内
5. **リソース使用量**: 効率的利用

### アラート設定

- ビルド失敗: 即座にアラート
- テスト失敗: 即座にアラート
- 実行時間超過: 警告
- 連続失敗: エスカレーション

## 🔒 セキュリティ標準

### 必須セキュリティチェック

1. **依存関係監査**: 高/重要脆弱性なし
2. **秘密情報スキャン**: 機密情報の検出
3. **コード品質**: ESLint + TypeScript
4. **Permission**: 最小権限の原則

### シークレット管理

- GitHub Secrets使用
- 環境別管理
- ローテーション計画

## 📈 継続的改善

### KPI目標

- ESLintエラー数: 0個維持
- テストカバレッジ: 80%以上維持
- ビルド時間: 15分以内
- デプロイ頻度: 1日1回以上

### レビュープロセス

1. **週次**: ワークフロー実行統計レビュー
2. **月次**: パフォーマンス最適化
3. **四半期**: 標準見直し

## 🚫 禁止事項

- main/developブランチへの直接プッシュ
- テストスキップでのマージ
- セキュリティチェック無視
- 未承認の外部Action使用

## ✅ 推奨事項

- 統合CI/CDワークフロー優先使用
- 並列実行によるパフォーマンス向上
- 適切なタイムアウト設定
- 詳細なコメントとドキュメント
- 失敗時の分かりやすいエラーメッセージ
