# プレフィックス付きラベルシステム - 使用ガイド

## 🎉 概要

PMPLearningManagementリポジトリでは、Issue作成時のSuggestionsで見やすくするため、全ラベルにカテゴリ識別用の短いプレフィックスを追加しました。

## 📋 期待される改善効果

### Issue作成時のメリット

- ✅ **カテゴリごとにまとまって表示** - アルファベット順で同じプレフィックスが連続表示
- ✅ **目的のラベルが見つけやすい** - カテゴリを先頭で識別可能
- ✅ **統一感のある命名規則** - チーム全体で一貫したラベル使用
- ✅ **楽しいラベル表現を維持** - 絵文字と親しみやすい表現は保持

## 🏷️ ラベルカテゴリ一覧

### T: TYPE - 開発クエストタイプ (8個)

タスクの種類を表します。Issue作成時に最初に選択すべきラベルです。

- `T:🐛 バグハンター` - バグ・不具合の報告
- `T:✨ 新機能の魔法使い` - 新機能の要求・提案
- `T:🚀 パフォーマンス・スピードスター` - パフォーマンス最適化
- `T:🎨 デザインの芸術家` - UI/UXデザイン改善
- `T:🔧 リファクタリングの匠` - コード品質向上・リファクタリング
- `T:📚 知識の伝道師` - ドキュメント作成・更新
- `T:🧪 テストの科学者` - テスト作成・改善
- `T:🔐 セキュリティの守護者` - セキュリティ強化

### P: PRIORITY - 優先度エネルギー (5個)

タスクの優先度を表します。緊急度に応じて選択します。

- `P:🚨 緊急出動` - 本番停止・重大な機能障害
- `P:🔥 高優先度` - ユーザー体験に大きく影響
- `P:⭐ 標準` - 通常の優先度・バランス重要
- `P:🌱 低優先度` - 時間があるときに対応
- `P:💡 アイデア` - 将来への投資・実験的

### A: AREA - PMP学習ドメイン (10個)

機能領域やPMP知識エリアを表します。

- `A:🎯 統合管理` - フロントエンド・バックエンド統合
- `A:📋 スコープ管理` - 機能要件・範囲定義
- `A:⏰ スケジュール管理` - 開発スケジュール・マイルストーン
- `A:💰 コスト管理` - リソース最適化・効率性
- `A:🏅 品質管理` - テスト・品質向上
- `A:👥 チームワーク` - コラボレーション・人的資源
- `A:📡 コミュニケーション` - UI/UX・情報共有
- `A:⚠️ リスク管理` - セキュリティ・エラーハンドリング
- `A:🤝 調達管理` - 外部API・ライブラリ統合
- `A:🎭 ステークホルダー・エンゲージメント` - ユーザー体験・フィードバック

### L: LEVEL - チャレンジレベル (5個)

タスクの難易度・複雑さを表します。

- `L:🌟 初心者への贈り物` - プログラミング初心者歓迎
- `L:⚡ 駆け出し冒険者` - 基礎スキル前提の軽いチャレンジ
- `L:🔥 熟練者の挑戦` - 経験豊富な開発者向け
- `L:👑 マスター級の伝説` - アーキテクチャ設計レベル
- `L:🏆 エピック・クエスト` - 複数週間の大型プロジェクト

### S: STATUS - 作業フロー状況 (7個)

タスクの進捗状況を表します。開発フローに沿って更新します。

- `S:🔍 調査中` - 情報収集・分析段階
- `S:✅ 準備完了` - 要件整理完了・開発可能
- `S:⚡ 開発中` - コーディング・実装中
- `S:⏸️ 一時停止` - 他の優先課題対応中
- `S:👀 レビュー待ち` - コードレビュー・品質確認
- `S:🎯 テスト中` - 動作確認・バグ探し
- `S:🚫 ブロック中` - 外部要因で作業停止

### TM: TEAM - コミュニティ協働 (7個)

チームワークやコラボレーションを表します。

- `TM:🌟 チーム・クエスト` - 複数人での協働作業
- `TM:🎓 メンター募集` - 経験者のアドバイス求む
- `TM:🚀 新人歓迎` - プログラミングデビューに最適
- `TM:💬 ディスカッション` - 技術相談・質問・アイデア交換
- `TM:🎯 ペアプログラミング` - リアルタイムコラボレーション
- `TM:📚 ナレッジシェア` - 知識共有・チュートリアル作成
- `TM:🎨 デザインレビュー` - UI/UX改善提案

### SP: SPECIAL - 特別認定 (7個)

特別な意味を持つラベルです。

- `SP:🏅 コミュニティ・ヒーロー` - コミュニティ貢献度大
- `SP:🎭 オールラウンダー` - フロントエンド・バックエンド横断
- `SP:⚠️ 破壊的変更` - 既存機能への影響あり
- `SP:🔄 重複問題` - 過去の議論と重複
- `SP:❌ 今回は見送り` - タイミング的に実装しない
- `SP:🎯 MVP必須` - 最小価値製品に必要
- `SP:🚀 将来の夢` - 長期的なビジョン

## 🎯 使用例・ベストプラクティス

### バグ報告の場合

```
基本ラベル：T:🐛 バグハンター
優先度：P:🔥 高優先度 (ユーザー体験に影響する場合)
状況：S:🔍 調査中 (初期状態)
```

### 新機能提案の場合

```
基本ラベル：T:✨ 新機能の魔法使い
優先度：P:💡 アイデア (アイデア段階)
レベル：L:⚡ 駆け出し冒険者 (実装の複雑さに応じて)
状況：S:🔍 調査中
```

### パフォーマンス改善の場合

```
基本ラベル：T:🚀 パフォーマンス・スピードスター
エリア：A:🎯 統合管理 (全体的な改善の場合)
優先度：P:⭐ 標準
状況：S:✅ 準備完了
```

### チーム作業が必要な場合

```
基本ラベル：T:✨ 新機能の魔法使い
チーム：TM:🌟 チーム・クエスト
レベル：L:🔥 熟練者の挑戦
状況：S:🔍 調査中
```

## 🔧 Issueテンプレートとの統合

各Issueテンプレートには、適切なプレフィックス付きラベルが自動設定されます：

- **バグ報告**: `["T:🐛 バグハンター", "P:🔥 高優先度", "S:🔍 調査中"]`
- **機能提案**: `["T:✨ 新機能の魔法使い", "P:💡 アイデア", "S:🔍 調査中"]`
- **改善提案**: `["T:🚀 パフォーマンス・スピードスター", "P:⭐ 標準", "S:🔍 調査中"]`
- **学習コンテンツ**: `["T:📚 知識の伝道師", "A:📚 ナレッジシェア", "P:⭐ 標準"]`
- **ドキュメント**: `["T:📚 知識の伝道師", "TM:📚 ナレッジシェア", "P:🌱 低優先度"]`
- **質問・サポート**: `["TM:💬 ディスカッション", "TM:🎓 メンター募集", "P:⭐ 標準"]`

## 🎮 ゲーミフィケーション要素

このラベルシステムには以下のゲーミフィケーション要素が含まれています：

- **RPG風レベルシステム** - タスクの複雑さをレベルで表現
- **冒険クエスト表現** - 各課題を楽しい冒険として表現
- **達成感の演出** - 完了時の達成感を重視
- **コミュニティ協働** - チームワークを積極的に促進
- **成長の可視化** - PMP学習ドメインで成長を実感

## 🚀 今後の活用方法

1. **Issue作成時**: テンプレートからラベルが自動設定される
2. **ラベル追加時**: プレフィックスで目的のラベルを素早く発見
3. **進捗管理**: S:ラベルで開発フローを可視化
4. **チーム協働**: TM:ラベルでコラボレーションを促進
5. **優先度判断**: P:ラベルでタスクの緊急度を把握
