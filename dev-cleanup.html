🧹 開発環境クリーンアップツール

このツールは開発環境のService Workerとキャッシュをクリーンアップするためのツールです。

実行結果:

手動クリーンアップ手順:

  1. 開発ツール（F12）を開く
  2. Application タブを開く
  3. Service Workers セクションを開く
  4. "Unregister" をクリック
  5. Storage セクションで "Clear site data" をクリック
  6. ページを完全リロード（Ctrl+Shift+R / Cmd+Shift+R）

コンソールで実行:

// Service Workerをアンレジスター
navigator.serviceWorker.getRegistrations()
  .then(r => r.forEach(w => w.unregister()));

// キャッシュをクリア
caches.keys()
  .then(k => Promise.all(k.map(n => caches.delete(n))));
